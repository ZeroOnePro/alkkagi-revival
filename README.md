# 알까기 온라인 REVIVAL

2011년 게임의 규칙을 바탕으로 만든 비공식 HTML 복각 프로토타입입니다. 원본 게임의 이미지와 음원은 사용하지 않습니다.

## 플레이

https://zeroonepro.github.io/alkkagi-revival/

내 돌을 누르고 쏘고 싶은 방향의 반대로 당겼다가 놓으세요. AI 대전과 한 기기 2인 대전, 4가지 맵과 포진을 지원합니다.

효과음은 Web Audio API로 합성합니다. 모바일에서는 화면을 처음 터치한 후 소리가 활성화됩니다. 효과음 버튼으로 켜거나 끌 수 있습니다.

## 실행 및 배포

`index.html` 하나로 실행되며 빌드나 의존성 설치가 필요 없습니다. GitHub Pages에서 `main` 브랜치의 루트(`/`)를 배포합니다.
